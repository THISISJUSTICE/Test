# Draw.io GitHub Pages demo

`Docs/Sample.drawio` 파일 하나만 수정하면 GitHub Pages의 구조도도 바뀝니다.

**설정:** Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save.

배포 주소: `https://<GitHub-사용자명>.github.io/<저장소명>/`

README에는 `[구조도 보기](https://<GitHub-사용자명>.github.io/<저장소명>/)` 링크를 추가하세요.

외부 diagrams.net viewer 스크립트를 사용하므로 온라인 연결이 필요합니다.
